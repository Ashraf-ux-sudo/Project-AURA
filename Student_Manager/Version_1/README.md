# Student Manager V1

## Overview

Student Manager V1 is the first basic version of the Student Manager created as part of Project AURA.

The purpose of V1 was to learn how Python can be used to create a simple system for storing student information.

## Features

The Student Manager stores basic student information such as:

- Student name
- Grade
- Subjects
- Tasks
- Schedule
- Test records

## What I Learned

During the development of V1, I learned:

- Python classes
- Objects
- Attributes
- Lists
- Basic Object-Oriented Programming
- How to store information inside objects

## Limitations

Version 1 mainly focuses on storing information.

It does not yet contain:

- Advanced subject management
- Connected objects
- Automatic analysis
- Intelligent recommendations
- AI capabilities

## Next Version

Version 2 improves the architecture by introducing separate objects for:

- Students
- Subjects
- Tasks
- Schedule items
- Test records

These objects can also reference one another.

## Status

Version 1 is complete and serves as the foundation for Student Manager V2.
